## Q版批量生成建议

### 生成顺序
1. 先生成每个角色的**基础Q版立绘**（使用默认提示词）
2. 根据需要生成**表情变体**（happy、wink、shy等）
3. 最后生成**特殊场景**（节日主题等）

### 一致性保持
- **固定Seed**: 记录满意图片的Seed值，用于生成变体
- **相同参数**: 所有角色使用相同的Steps、CFG Scale、Sampler
- **统一风格**: 保持chibi风格词一致
- **使用LoRA**: 如有Q版LoRA，所有角色使用相同LoRA

### Q版质量检查清单
- [ ] 头身比例协调（2-3头身）
- [ ] 四肢圆润短小
- [ ] 面部圆润可爱
- [ ] 眼睛大而闪亮
- [ ] 整体风格Q版一致
- [ ] 无正常比例混入
- [ ] 色彩明亮鲜艳
