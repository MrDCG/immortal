# 云上香项目 - 总计划

## 项目概述

开发一款"云上香"网页应用，让用户可以在线为五路财神和月老上香祈福，采用动漫风格设计，提供流畅的互动体验，打造一个治愈、解压的线上祈福空间。

---

## 项目目标

### 主要目标
- 为用户提供便捷、有趣的线上祈福体验
- 结合动漫风格和互动体验，吸引年轻用户
- 打造治愈、解压的精神寄托空间

### 商业目标
- 积累用户流量，建立品牌认知
- 为后续商业化（如周边、增值功能）打下基础

---

## 技术选型

| 技术类别 | 选型方案 | 理由 |
|----------|----------|------|
| 前端框架 | Vue 3 | 生态成熟，响应式系统优雅 |
| 构建工具 | Vite 5 | 开发体验好，HMR快速 |
| 语言 | TypeScript | 类型安全，代码可维护性高 |
| 动画库 | VueUse + CSS Transition | 轻量级动画方案 |
| 样式方案 | Tailwind CSS | 快速开发，原子化CSS |
| 状态管理 | Pinia | Vue官方推荐，简洁强大 |
| 数据存储 | localStorage | 无需后端，降低部署复杂度 |
| 部署方式 | 静态托管 | 成本低，运维简单 |

## 核心数据结构

### 神仙数据结构
```typescript
interface God {
  id: string;                // 唯一标识
  name: string;              // 名称
  title: string;             // 封号（如"东路财神"）
  direction: string;         // 方位（东/西/南/北/中）
  type: 'wealth' | 'love';   // 类型
  image: string;             // 立绘图片路径
  bgImage?: string;          // 背景图路径
  color: string;             // 主题色
  blessings: string[];       // 该神仙的祈福语
}
```

### 上香记录结构
```typescript
interface IncenseRecord {
  godId: string;             // 神仙ID
  date: string;              // 日期 YYYY-MM-DD
  count: number;             // 上香次数
}
```

### 全局状态结构
```typescript
interface AppState {
  currentGodIndex: number;   // 当前神仙索引
  gods: God[];               // 所有神仙数据
  incenseRecords: Record<string, IncenseRecord>; // 上香记录
}
```

## 技术难点与解决方案

| 技术难点 | 解决方案 | 技术选型 |
|----------|----------|----------|
| 香燃烧动画 | Canvas粒子系统 + requestAnimationFrame | 原生Canvas API |
| 烟雾效果 | CSS滤镜透明度渐变 + 多层叠加 | CSS3 Animation |
| 神仙微动效 | CSS关键帧动画（眨眼、微笑） | CSS Keyframes |
| 移动端滑动 | Touch事件监听 + 阈值判断 | Touch Events API |
| 数据持久化 | localStorage + JSON序列化 | Web Storage API |
| 性能优化 | 图片懒加载、代码分割、资源预加载 | Vue异步组件 + import() |
| 浏览器兼容 | PostCSS + Autoprefixer | PostCSS |

## 风险与应对

| 风险项 | 风险等级 | 应对措施 |
|--------|----------|----------|
| 素材制作延期 | 中 | 先用占位图开发，后期替换 |
| 动画性能问题 | 中 | 使用CSS transform，避免重排 |
| 浏览器兼容性 | 低 | 使用Autoprefixer，Polyfill |
| localStorage限制 | 低 | 数据量小，无需担心 |
| 移动端适配 | 中 | 响应式设计，触摸优化 |
