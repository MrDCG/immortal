# 02-UI设计与资源准备计划

## 计划概述

**阶段目标**：完成视觉设计和素材准备，为开发阶段提供完整的设计规范和资源文件

**预计工期**：3-5天

**前置条件**：
- 项目初始化完成
- 设计工具可用（Figma/Sketch/Photoshop）

## 二、微动效设计

### 2.1 待机动画

| 动画 | 描述 | 时长 | 循环 |
|------|------|------|------|
| 呼吸浮动 | 轻微上下浮动 | 3s | 是 |
| 眨眼 | 自然眨眼 | 0.2s | 随机(3-5s) |
| 衣袂飘动 | 衣服轻微摆动 | 2s | 是 |
| 头发飘动 | 头发轻微摆动 | 2.5s | 是 |

### 2.2 交互动画

| 触发 | 动画效果 | 时长 |
|------|----------|------|
| 鼠标悬停 | 身体前倾、微笑放大 | 0.3s |
| 点击 | 欢快跳动、闪光效果 | 0.5s |
| 连续上香3次 | 全身发光、花瓣飘落 | 2s |

### 2.3 切换动画

| 方向 | 效果 | 时长 |
|------|------|------|
| 下一个 | 从右侧滑入，当前向左淡出 | 0.4s |
| 上一个 | 从左侧滑入，当前向右淡出 | 0.4s |

## 四、UI组件设计

### 4.1 上香按钮

**设计方案**：

| 状态 | 样式 |
|------|------|
| 默认 | 金色渐变圆形，香炉图标，阴影 |
| 悬停 | 放大1.1倍，增强阴影 |
| 点击 | 缩小0.95倍，涟漪效果 |
| 禁用 | 半透明，无交互 |

**尺寸规格**：
- 桌面：80x80px
- 移动端：64x64px

### 4.2 切换导航

**左右箭头按钮**：

| 属性 | 规格 |
|------|------|
| 形状 | 半透明圆形 |
| 颜色 | 白色 20% 透明度 |
| 尺寸 | 48x48px |
| 图标 | 箭头 SVG |
| 位置 | 屏幕左右边缘，垂直居中 |

### 4.3 计数器组件

**设计方案**：
- 位置：右上角
- 样式：半透明卡片，白色文字带阴影
- 文案：「今日上香：X次」
- 字体：16px，加粗

### 4.4 祈福语弹窗

**设计方案**：
- 背景：半透明黑色遮罩
- 弹窗：圆角矩形，渐变边框
- 文字：大字号，金色/粉色渐变
- 动画：淡入 + 缩放
- 显示时长：2秒

## 五、上香动画设计

### 5.1 香燃烧动画

**阶段分解**：

| 阶段 | 描述 | 时长 |
|------|------|------|
| 出现 | 香从底部向上滑入 | 0.3s |
| 燃烧 | 香头逐渐缩短，火星闪烁 | 2.4s |
| 消失 | 香燃尽后淡出 | 0.3s |

**视觉规格**：
- 香的长度：150px
- 香的粗细：3px
- 香头颜色：橙红渐变
- 香身颜色：棕色/深红

### 5.2 烟雾效果

**设计要点**：
- 使用粒子系统
- 烟雾从香头向上飘散
- 逐渐扩散并变淡
- 左右轻微摇摆

**粒子参数**：
- 数量：20-30个
- 上升速度：1-2px/frame
- 扩散范围：逐渐变大
- 透明度：从0.6到0

## 七、资源文件规范

### 7.1 图片资源命名规范

```
public/assets/
├── gods/
│   ├── {god_id}/
│   │   ├── default.png        # 默认立绘
│   │   ├── blink.png          # 眨眼帧（可选）
│   │   ├── happy.png          # 开心表情
│   │   └── sprite.png         # 精灵图（可选）
│   └── common/
│       └── frame.png          # 通用边框
├── backgrounds/
│   ├── wealth-bg.jpg          # 财神背景
│   └── love-bg.jpg            # 月老背景
├── effects/
│   ├── smoke.png              # 烟雾粒子
│   ├── flower-petal.png       # 花瓣
│   ├── coin.png               # 金币
│   └── glow.png               # 光效
├── sounds/
│   ├── incense.mp3            # 上香音效
│   ├── click.mp3              # 点击音效
│   └── bgm.mp3                # 背景音乐（可选）
└── icons/
    ├── incense.svg            # 上香图标
    ├── arrow-left.svg         # 左箭头
    └── arrow-right.svg        # 右箭头
```

### 7.2 文件规格

| 资源类型 | 格式 | 尺寸限制 | 文件大小限制 |
|----------|------|----------|--------------|
| 神仙立绘 | PNG/WebP | 500x800px | < 300KB |
| 背景图 | JPG/WebP | 1920x1080px | < 500KB |
| 粒子素材 | PNG/WebP | 64x64px | < 50KB |
| 图标 | SVG | - | < 10KB |
| 音效 | MP3/OGG | - | < 100KB |

### 7.3 图片优化建议

1. **格式选择**：
   - 照片类背景：JPG/WebP
   - 透明图：PNG/WebP
   - 图标：SVG

2. **压缩工具**：
   - TinyPNG / TinyJPG
   - Squoosh（Google）
   - ImageOptim

3. **响应式处理**：
   - 准备多种分辨率
   - 使用 srcset 属性

## 九、临时方案

如设计资源尚未就绪，可采用以下临时方案：

### 9.1 占位图片

使用以下方式创建临时占位图：

```typescript
// 临时代码中的占位方案
const placeholderGods = {
  bigan: {
    image: 'https://via.placeholder.com/500x800/D4AF37/FFFFFF?text=比干',
    color: '#D4AF37',
  },
  // ... 其他神仙
};
```

### 9.2 CSS临时绘制

使用CSS绘制简单的临时图形：

```css
.god-placeholder {
  width: 300px;
  height: 400px;
  background: linear-gradient(135deg, #D4AF37, #FFD700);
  border-radius: 20px;
}
```
